# one-line-of-wonder

One line of wonder. `main.py` writes the line to `/output/entry.txt` (and prints it):

> Tonight, light from a star that died before the first human opened an eye is landing on a sleeping child's eyelid.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
